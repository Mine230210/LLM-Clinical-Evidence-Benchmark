# Lost in the Evidence: Evaluating the Reliability of Large Language Models in Finding, Interpreting and Applying Clinical Evidence

## Overview

This repository contains the analysis scripts and supplementary figure-generation code accompanying the study *Lost in the Evidence: Evaluating the Reliability of Large Language Models in Finding, Interpreting and Applying Clinical Evidence*.

The study evaluates the reliability of general-purpose large language models (LLMs) across three dimensions of clinical evidence:

1. **Evidence visibility:** Identifying trial-derived adverse-event safety signals and retrieving their supporting evidence sources.
2. **Evidence disagreement:** Recognizing and classifying disagreement across clinical evidence syntheses.
3. **Evidence applicability:** Assessing whether findings from randomized controlled trials (RCTs) can be transferred to specific real-world clinical scenarios.

Three LLM services were evaluated through their official web interfaces:

- ChatGPT (GPT-5.3; OpenAI)
- DeepSeek (DeepSeek-V3.2; DeepSeek AI)
- Gemini (Gemini 3 Flash; Google)

Each benchmark item was evaluated twice per model, resulting in 1,596 recorded model responses.

## Benchmark Overview

| Benchmark | Reference items | Model responses | Evaluation target |
|---|---:|---:|---|
| Evidence visibility | 170 | 1,020 | Joint success in risk identification and evidence-source attribution |
| Evidence disagreement | 36 | 216 | Accuracy of high- or low-controversy classification |
| Evidence applicability | 60 | 360 | Applicability verdicts and supporting key reasons |
| **Total** | **266** | **1,596** | |

The three benchmarks cover different aspects of clinical evidence interpretation:

- **Visibility:** 170 trial-derived safety signals, including 85 PubMed-linked and 85 unlinked trials.
- **Disagreement:** 36 clinical questions, including 24 high-controversy and 12 low-controversy questions.
- **Applicability:** 60 clinical scenarios derived from 43 diabetes-related RCTs.

## Statistical Analysis

The analysis scripts implement the statistical procedures described in the manuscript and Supplementary Information.

- Performance measures are calculated at the response level.
- Strict and lenient accuracy are calculated at the benchmark-item level.
- Repeated-response reproducibility is assessed using observed agreement and unweighted Cohen's κ.
- Confidence intervals are estimated using 20,000 nonparametric item-cluster bootstrap replicates, preserving repeated evaluations and model-level pairing within each item.
- Bootstrap resampling is stratified by PubMed linkage for evidence visibility and by controversy level for evidence disagreement. Evidence applicability scenarios are resampled without stratification.
- Between-model comparisons use paired permutation tests with 100,000 iterations and Holm correction within each benchmark.

For evidence visibility, repeated-response reproducibility is assessed using binary joint-success classifications. The latest estimates of Cohen's κ and their 95% confidence intervals are:

| Model | Cohen's κ | 95% CI |
|---|---:|---|
| ChatGPT | 0.161 | −0.038 to 0.365 |
| DeepSeek | 0.435 | 0.269 to 0.588 |
| Gemini | 0.583 | 0.435 to 0.716 |

## Reproducibility and Data Availability Boundaries

Once publicly released, the dataset will contain the recorded model responses and reference standards required for the analyses described above.

For evidence applicability, human-assigned key-reason quality ratings will not be included in the public dataset. Accordingly, the release will support reproduction of the verdict-based analyses but will not independently reproduce human-rated key-reason accuracy or analyses requiring those ratings.

This restriction preserves the predefined data-sharing boundary while allowing independent examination of the released model responses and other benchmark results.

## Running the Analysis

### Requirements

- Python 3.10 or later
- Dependencies listed in `requirements.txt`

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

When the dataset is publicly released, place the six benchmark CSV files in a local `data/` directory using the filenames listed above. The data files are excluded from version control and must not be committed to this repository.

Run the evidence visibility analysis:

```bash
python analysis/task1_analysis.py \
  --gold data/Task1_Gold.csv \
  --responses data/Task1_Responses.csv \
  --output-dir outputs/task1
```

Run the evidence disagreement analysis:

```bash
python analysis/task2_analysis.py \
  --gold data/Task2_Gold.csv \
  --responses data/Task2_Responses.csv \
  --output-dir outputs/task2
```

Run the public-mode evidence applicability analysis:

```bash
python analysis/task3_analysis.py \
  --gold data/Task3_Gold.csv \
  --responses data/Task3_Responses.csv \
  --output-dir outputs/task3
```

This Task 3 command reproduces applicability-verdict analyses only. Human key-reason ratings are restricted and are not included in the planned public dataset. The script does not infer or construct human ratings from model response text, and analyses requiring those ratings are not publicly reproducible.

After running all three analyses, generate Supplementary Figure 1:

```bash
python figures/supplementary_figure1.py \
  --task1-results outputs/task1 \
  --task2-results outputs/task2 \
  --task3-results outputs/task3 \
  --output-dir outputs/figures
```

The figure command creates PNG, PDF, and SVG versions of Supplementary Figure 1 in `outputs/figures/`.
